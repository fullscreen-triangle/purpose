## 🔍 Troubleshooting

### **Common Issues**

#### **ImportError: Module not found**

```bash
pip install -r requirements.txt
```

#### **Memory errors with large sequences**

Reduce sequence lengths in test data or increase system RAM.

#### **Visualization files not opening**

Ensure web browser supports HTML5 and JavaScript. Try different browser if issues persist.

#### **Permission errors creating output directories**

Run with appropriate permissions or change output directory in code.

### **Performance Optimization**

#### **For faster execution:**

- Use SSD storage for output files
- Increase Python memory limits if needed
- Run on multi-core systems for parallel processing

#### **For memory efficiency:**

- Set `save_intermediates=False` in demonstrations
- Process smaller batches of data
- Clear output directories periodically
